# Figure 3.x Entity Relationship Diagram Explanation

Figure 3.x တွင် District Education Resource Allocation System (DERAS) ၏ အဓိက data table (18) ခုနှင့် ၎င်းတို့အကြားရှိ relationship များကို ဖော်ပြထားသည်။ Diagram အတွင်း table တစ်ခုစီ၏ `id` သည် Primary Key (PK) ဖြစ်ပြီး record တစ်ခုစီကို မတူညီစွာ သတ်မှတ်ပေးသည်။ အခြား table များတွင်ပါဝင်သည့် `*_id` field များသည် Foreign Key (FK) များဖြစ်ကာ သက်ဆိုင်ရာ parent table ၏ `id` ကို ရည်ညွှန်းသည်။ ထိုသို့ချိတ်ဆက်ထားခြင်းကြောင့် academic year, township, grade, book နှင့် distribution record များကို မှန်ကန်စွာ ဆက်စပ်သိမ်းဆည်းနိုင်ပြီး data ထပ်နေမှုနှင့် မကိုက်ညီမှုများကို လျှော့ချနိုင်သည်။

Diagram ၏ အခြေခံ master data အဖြစ် `academic_year`, `township`, `school_level`, `grade` နှင့် `book_name` table များကို အသုံးပြုထားသည်။ `academic_year` သည် စနစ်တွင် အသုံးပြုသော ပညာသင်နှစ်၊ လက်ရှိအသုံးပြုနေသောနှစ်နှင့် active status ကို သိမ်းဆည်းသည်။ `township` သည် ခွဲဝေပေးရမည့် မြို့နယ်အချက်အလက်ကို သိမ်းဆည်းပြီး `school_level` နှင့် `grade` တို့သည် ကျောင်းအဆင့်နှင့် အတန်းအလိုက် အချက်အလက်ကို စီမံပေးသည်။ `grade.school_level_id` ဖြင့် အတန်းတစ်ခုသည် သက်ဆိုင်ရာ school level တစ်ခုအောက်တွင်ရှိကြောင်း ဖော်ပြသည်။ ထို့နောက် `book_name.grade_id` သည် စာအုပ်အမည်တစ်ခုကို သက်ဆိုင်ရာအတန်းနှင့် ချိတ်ဆက်ပေးသဖြင့် စာအုပ်၊ အတန်းနှင့် ပညာသင်နှစ်အလိုက် record များကို တိကျစွာ စီမံနိုင်သည်။

ကျောင်းသားဦးရေ၊ စာအုပ်ခွဲဝေမှုနှင့် လက်ကျန်စာရင်းများကို `quota`, `allocation_plan`, `allocation_plan_township`, `textbook`, `stock` နှင့် `previous_year_balance` table များဖြင့် စီမံထားသည်။ `quota` table တွင် academic year, township နှင့် grade အလိုက် student quantity ကို မှတ်တမ်းတင်သည်။ ထို quota အချက်အလက်များကို အသုံးပြု၍ `allocation_plan` တွင် စာအုပ်လက်ခံရရှိပမာဏနှင့် package အရေအတွက်ကို စီစဉ်နိုင်သည်။ `allocation_plan_township` သည် allocation plan တစ်ခု၏ မြို့နယ်အလိုက် ခွဲဝေမည့်အချက်အလက်ကို သိမ်းဆည်းထားပြီး `textbook_id` နှင့် allocated quantity ဖြင့် အမှန်တကယ်ခွဲဝေမှုကို ချိတ်ဆက်သည်။ `stock` နှင့် `previous_year_balance` တို့သည် ယခင်နှစ်မှ လက်ကျန်၊ လိုအပ်သည့်ပမာဏနှင့် နောက်နှစ်သို့ သယ်ဆောင်သွားမည့် balance များကို စစ်ဆေးနိုင်စေသည်။

Teacher guide လုပ်ငန်းစဉ်ကို `teacher_guide`, `tg_township_allocation`, `teacher_guide_issue` နှင့် `tg_issue_township` table များဖြင့် အဆင့်လိုက် စီမံထားသည်။ `teacher_guide` table သည် စာအုပ်အမည်၊ guide type နှင့် စုစုပေါင်း quota ကို သိမ်းဆည်းသည်။ `tg_township_allocation` တွင် academic year နှင့် township အလိုက် teacher guide ခွဲဝေမည့် quantity ကို မှတ်တမ်းတင်ပြီး၊ ထို record မှ `teacher_guide_issue` ကိုဖန်တီးကာ issued quantity နှင့် issue date ကို သိမ်းဆည်းသည်။ နောက်ဆုံး `tg_issue_township` သည် issue record တစ်ခုကို မြို့နယ်အလိုက် ထပ်မံအသေးစိတ်ခွဲထားသောကြောင့် teacher guide ထုတ်ပေးမှုကို trace လုပ်နိုင်သည်။ ထို့အပြင် `school_supply` table သည် academic year, township နှင့် grade အလိုက် school supply item, rate နှင့် quantity ကို သိမ်းဆည်းပြီး ကျောင်းသုံးပစ္စည်းခွဲဝေမှုကို ထိန်းချုပ်ပေးသည်။

System security နှင့် user access အတွက် `role` နှင့် `user` table များကို အသုံးပြုထားသည်။ `role` table တွင် Super Admin နှင့် Admin ကဲ့သို့ role အမျိုးအစားများကို သိမ်းဆည်းပြီး `user.role_id` ဖြင့် user account တစ်ခုချင်းစီကို role တစ်ခုနှင့် ချိတ်ဆက်ထားသည်။ `user.township_id` သည် လိုအပ်ပါက user တာဝန်ယူသည့် township ကို သတ်မှတ်နိုင်စေသည်။ စုစုပေါင်းအားဖြင့် Figure 3.x သည် master data မှစ၍ quota entry, allocation planning, textbook and stock distribution, teacher guide issue, school supply allocation နှင့် user access control အထိ data စီးဆင်းမှုကို ပြသထားသော database blueprint ဖြစ်သည်။ Diagram တွင်ပြထားသော PK နှင့် FK relationship များသည် record များကို မှန်ကန်စွာချိတ်ဆက်ပေးပြီး DERAS စနစ်၏ report, search နှင့် yearly allocation work များကို ယုံကြည်စိတ်ချစွာ ဆောင်ရွက်နိုင်စေသည်။

*Figure 3.x. Entity Relationship Diagram of the District Education Resource Allocation System (DERAS).*
