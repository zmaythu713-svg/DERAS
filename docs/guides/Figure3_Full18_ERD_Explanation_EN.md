# Figure 3.x Entity Relationship Diagram Explanation

Figure 3.x presents the eighteen main data tables of the District Education Resource Allocation System (DERAS) and the relationships between them. In the diagram, the `id` field in each table is the Primary Key (PK), which uniquely identifies every record. Fields ending in `*_id` are Foreign Keys (FKs) that refer to the `id` field of another related table. These links allow the system to connect academic years, townships, grades, books, and distribution records correctly. They also reduce duplicated data and help prevent inconsistent records.

The main master-data tables are `academic_year`, `township`, `school_level`, `grade`, and `book_name`. The `academic_year` table stores the school year, current-year status, and active status used throughout the system. The `township` table stores the townships that receive allocated resources. The `school_level` and `grade` tables organize education levels and individual grades. The foreign key `grade.school_level_id` shows that each grade belongs to one school level. In the same way, `book_name.grade_id` connects a book title to the appropriate grade. These master tables provide consistent reference data for all allocation and distribution work.

Student quotas, textbook allocation, and stock information are managed through the `quota`, `allocation_plan`, `allocation_plan_township`, `textbook`, `stock`, and `previous_year_balance` tables. The `quota` table records the student quantity for an academic year, township, and grade. This information supports planning in the `allocation_plan` table, which records the number of books received and the number of books in each package. The `allocation_plan_township` table stores the allocation detail for each township and links the plan to the related textbook record and allocated quantity. The `stock` and `previous_year_balance` tables store previous balances, required quantities, and carry-forward balances so that the system can check available resources and plan for the next academic year.

Teacher-guide processing is managed by the `teacher_guide`, `tg_township_allocation`, `teacher_guide_issue`, and `tg_issue_township` tables. The `teacher_guide` table stores the book title, guide type, and total quota. The `tg_township_allocation` table records the quantity allocated to each township for a specific academic year. A related `teacher_guide_issue` record is then created to store the issued quantity and issue date. Finally, the `tg_issue_township` table stores issue details by township. This sequence makes the teacher-guide distribution process traceable from the initial allocation to the final issue record. In addition, the `school_supply` table stores the school-supply item, rate, and quantity for each academic year, township, and grade.

System security and user access are managed through the `role` and `user` tables. The `role` table stores role types, such as Super Admin and Admin. Each user account is linked to one role through `user.role_id`, which allows the system to control access to protected functions. The field `user.township_id` can also identify the township assigned to a user when required. Overall, Figure 3.x acts as the database blueprint for DERAS. It shows how master data supports quota entry, allocation planning, textbook and stock distribution, teacher-guide issuing, school-supply allocation, and user access control. The PK and FK relationships shown in the diagram maintain data integrity and support reliable reporting, searching, and yearly allocation work.
